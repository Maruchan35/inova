# inova

Proyecto del equipo para la competencia.

## Cómo empezar

```bash
git clone https://github.com/Maruchan35/inova.git
cd inova
```

## Flujo de trabajo

1. Antes de empezar: `git pull`
2. Crea una rama para tu tarea: `git checkout -b nombre-tarea`
3. Guarda cambios: `git add .` y `git commit -m "qué hiciste"`
4. Súbelos: `git push -u origin nombre-tarea`
5. Abre un Pull Request en GitHub para unirlo a `main`
